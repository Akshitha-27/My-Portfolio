# Sheela Akshitha — Portfolio Website

A responsive, modern dark portfolio built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page content and structure
- `style.css` — dark theme, responsive layout, and styling
- `script.js` — mobile menu and project detail dialogs

## Run locally
1. Download and extract all files into the same folder.
2. Open `index.html` in a browser. No installation is required.

## Before publishing
- Replace `your.email@example.com` with your actual email.
- Replace the `#` GitHub and LinkedIn links with your profile URLs.
- Replace the profile-photo placeholder with your photo if desired.
- The three projects are ideas, not completed projects. Build them before describing them as finished work.
- Adjust the skills and proficiency bars to reflect your actual abilities.

## Publish free with GitHub Pages
1. Sign in or create an account at https://github.com/.
2. Create a new public repository, for example `sheela-akshitha-portfolio`.
3. Upload `index.html`, `style.css`, and `script.js` to the repository root.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
6. Wait for deployment. GitHub will show your public website URL in the Pages section.
